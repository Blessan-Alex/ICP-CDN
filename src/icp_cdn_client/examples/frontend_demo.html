🚀 Basic Usage

Here's how other canisters can use the CDN library:

1. Add to Cargo.toml

[dependencies] icp-cdn-client = { path = "../icp-cdn-client" }

2. Create a CDN Client

use icp_cdn_client::{CdnClient, CYCLES_SMALL_UPLOAD}; use candid::Principal; let cdn_client = CdnClient::new( Principal::from_text("your-cdn-canister-id")? );

3. Upload Content

let cid = cdn_client.upload_asset( file_bytes, "image/png".to_string(), CYCLES_SMALL_UPLOAD, ).await?; println!("Uploaded with CID: {}", cid);

4. Retrieve Content

let content = cdn_client.get_asset(cid).await?; println!("Retrieved {} bytes", content.len());

⚡ Advanced Features

User Account Management

// Get user account with tier information let account = cdn_client.get_user_account().await?; println!("User tier: {:?}", account.tier); println!("Cycles balance: {}", account.cycles_balance); // Deposit cycles let updated_account = cdn_client.deposit_cycles(1000000000).await?;

Cost Estimation

// Estimate upload cost let upload_cost = cdn_client.estimate_upload_cost(file_size).await?; // Estimate storage cost let storage_cost = cdn_client.estimate_storage_cost(file_size, 24).await?;

Automatic IPFS Fallback

// Try cache first, fallback to IPFS let content = cdn_client.get_asset_with_fallback(cid).await?;

🔗 Integration Examples

OpenChat Integration

#[ic_cdk::update] async fn upload_user_avatar(user_id: String, avatar_bytes: Vec) -> Result { let cdn_client = CdnClient::new(canister_id); let cid = cdn_client.upload_asset( avatar_bytes, "image/png".to_string(), CYCLES_SMALL_UPLOAD, ).await?; // Store CID in OpenChat's user data store_user_avatar_cid(user_id, cid.clone())?; Ok(cid) }

Caffeine Integration

#[ic_cdk::update] async fn upload_coffee_image(image_bytes: Vec) -> Result { let cdn_client = CdnClient::default(); // Uses default canister let cid = cdn_client.upload_asset( image_bytes, "image/jpeg".to_string(), CYCLES_MEDIUM_UPLOAD, ).await?; Ok(cid) }
