# Cursor Prompt

I am building a CDN/cache prototype on the Internet Computer for a hackathon.  
I need code in **Rust (IC canister)** that demonstrates:

1. **Free hackathon feasibility**  
   - Each user gets a **10MB free cache tier**.  
   - Implement a simple **LRU eviction policy** so if they exceed quota, older entries are removed.  
   - Store cache entries as `HashMap<String, Vec<u8>>`.

2. **Scalability story**  
   - Add an enum `CacheTier` with limits:  
     - Free: 10MB  
     - Basic: 50MB  
     - Premium: 100MB  
     - Enterprise: 500MB  
   - User struct should track `tier`, `current_size`, and `entries`.

3. **Upgrade path (mocked)**  
   - Implement a function `upgrade_tier(user_id, new_tier)` that updates their limit (no billing required, just simulate it).  
   - Show how 100MB can be unlocked for Premium users.

4. **Hackathon demo plan**  
   - Start with Free tier (10MB).  
   - Provide sample functions:  
     - `put(user_id, key, data)` → stores data with eviction if above limit.  
     - `get(user_id, key)` → retrieves cached data.  
     - `stats(user_id)` → shows tier, size, usage.  

5. **Extra (for pitch)**  
   - Write a small function `simulate_costs(num_users: u64)` that prints out approximate cycle costs for storage (e.g., assume 1GB ≈ 1T cycles).  
   - This will let me show judges a “scaling cost” graph.

Keep the implementation **clean, simple, and hackathon-friendly**. I don’t need production-level code, just enough to demo the feasibility (free tier) and show the potential to scale (multi-tier + cost simulation).

   - Custom cache allocation (e.g., 500MB+ per user)
